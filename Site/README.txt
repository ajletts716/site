SATOSHI FONT FILES GO HERE
——————————————————————————

1. Go to fontshare.com/fonts/satoshi
2. Click "Download family" (free — the Fontshare license covers
   personal and commercial web use)
3. Unzip. Inside Fonts/Variable/ (or Web/fonts/) find:
     Satoshi-Variable.woff2
     Satoshi-VariableItalic.woff2
4. Drop both files into this folder. Done — the site picks
   them up automatically and stops using the Hanken fallback.

(If the download only gives you .ttf files, the WEB folder of
the zip has the .woff2 versions — use those.)
